# ZHIWJ Store - README

## Быстрый старт

### 1. Установка зависимостей
```bash
cd zhiwj-store
npm install
```

### 2. Настройка переменных окружения
Скопируйте `.env.local.example` в `.env.local` и заполните значения:

```bash
cp .env.local.example .env.local
```

**Необходимые ключи:**

#### Sanity CMS (база данных товаров)
1. Зарегистрируйтесь на [sanity.io](https://www.sanity.io)
2. Создайте проект → получите `projectId`
3. Создайте токен API в настройках проекта → `SANITY_API_TOKEN`

#### Clerk (аутентификация админа)
1. Зарегистрируйтесь на [clerk.com](https://clerk.com)
2. Создайте приложение → скопируйте ключи
3. Включите "Email Code" для магических ссылок

#### Stripe (оплата)
1. Зарегистрируйтесь на [stripe.com](https://stripe.com)
2. Получите тестовые ключи в Dashboard
3. Для продакшена используйте live-ключи

**Альтернатива для СНГ:** Если Stripe не работает в вашем регионе, используйте CloudPayments или локальный шлюз банка. Логика та же — создаёте ссылку на оплату.

### 3. Запуск разработки
```bash
npm run dev
```
Откройте http://localhost:3000

### 4. Деплой на Vercel
1. Залейте код на GitHub
2. Подключите репозиторий в [vercel.com](https://vercel.com)
3. Добавьте все переменные из `.env.local` в настройки Vercel
4. Нажмите Deploy

## Управление магазином

### Добавление товара
1. Перейдите на `/studio` (войдите как админ через меню "3 точки")
2. Нажмите **+ Create** → **Товар**
3. Заполните поля:
   - Название
   - Цена (TJS)
   - Фото (загрузите 3-5 изображений)
   - Размеры (S, M, L, XL)
   - Коллекция (Tamaddoon / Metomorfoz / Bahor / Dynamic)
   - История изделия (опционально)
4. Нажмите **Publish**

### Обработка заказов
1. В админке перейдите в раздел **Orders**
2. Новые заказы имеют статус "Ожидает оплаты" или "Оплачен"
3. Измените статус на "Отправлен" после отправки
4. После получения клиентом — "Доставлен"

### Настройка бота (Chatbase/Jigarik)
1. Зарегистрируйтесь на [chatbase.co](https://www.chatbase.co)
2. Загрузите базу знаний (PDF с описанием бренда на RU/TJ/EN)
3. Получите ID бота
4. Вставьте ID в `src/components/ChatbotWidget.tsx` вместо `YOUR_BOT_ID`

## Структура проекта

```
zhiwj-store/
├── src/app/
│   ├── layout.tsx          # Главный шаблон
│   ├── page.tsx            # Главная страница
│   ├── studio/             # Админка Sanity
│   ├── product/[slug]/     # Страница товара
│   ├── cart/               # Корзина
│   └── api/
│       ├── checkout/       # Создание платежа Stripe
│       └── webhook/        # Обработка успешной оплаты
├── src/components/
│   ├── Header.tsx          # Шапка с меню и языками
│   ├── HeroSlider.tsx      # Автопрокручивающийся слайдер
│   ├── ProductCard.tsx     # Карточка товара
│   └── ChatbotWidget.tsx   # Виджет бота
├── src/lib/
│   ├── sanity.ts           # Клиент Sanity
│   ├── store.ts            # Состояние корзины (Zustand)
│   └── utils.ts            # Утилиты
├── sanity/
│   ├── schema.ts           # Схема данных (товары, заказы)
├── sanity.config.ts        # Конфигурация Sanity Studio
└── .env.local              # Переменные окружения
```

## Техподдержка

При проблемах:
1. Проверьте `.env.local` — все ли ключи заполнены
2. Запустите `npm run build` для проверки ошибок компиляции
3. Проверьте консоль браузера на ошибки JavaScript
